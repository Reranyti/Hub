# Game & Project Hub

Настольное приложение для Windows: библиотека игр и проектов в одном окне. Подтягивает игры из Steam, сам считает время в играх вне Steam и следит за прогрессом.

## Возможности

- **Библиотека Steam.** Импорт игр, часов и даты последнего запуска; обложки, жанры и описания из магазина; достижения; вишлист со скидками.
- **Игры вне Steam.** Каталог (Minecraft Java и Bedrock, osu!, Roblox, Valorant, League of Legends и другие), игры Epic Games. Время считается автоматически, пока запущен процесс игры.
- **Скилл.** Графики роста по любым метрикам, ранги Valorant и LoL; для osu! и Steam-игр значения подтягиваются сами, без ключей.
- **Особые разделы.** Minecraft: миры и часы из статистики, базы с пересчётом координат в Незер, моды, цели. Roblox, osu!: свои списки.
- **Что поиграть.** Рулетка по подборкам и разбор библиотеки по статусам.
- **Итоги.** Статистика по часам, жанрам и «горе стыда».
- **Проекты.** Добавление из папки (язык, описание, ссылка на git), состояние git, открытие в VS Code и терминале.
- **Проекты автора.** Скачать и запустить любую версию игры или установить мод.
- **Быстрый поиск** по Ctrl+K, напоминания о перерыве и дневной лимит, резервные копии.

## Установка

Скачайте `GameProjectHub-Setup-Full.exe` из раздела Releases: это полная версия, в ней программа и эксклюзивные версии проектов автора (ставятся по выбору, интернет для них не нужен, каждый файл проверяется контрольной суммой). Установка идёт в профиль пользователя, права администратора не нужны. Файл не подписан цифровой подписью, поэтому Windows SmartScreen может показать предупреждение: нажмите «Подробнее» и «Выполнить в любом случае».

Для работы нужен Microsoft Edge WebView2 Runtime (в Windows 11 есть из коробки).

## Запуск из исходников

```bash
python -m pip install pywebview psutil
python app.py
```

Данные в этом режиме хранятся рядом с кодом.

## Сборка `.exe` и установщика

```bash
python -m pip install pyinstaller pillow pywebview psutil
python build.py
```

Результат в папке `dist`: `GameProjectHub-Setup.exe` (чистый установщик), `GameProjectHub-Setup-Full.exe` (то же плюс всё, что лежит в папке `exclusive` рядом со скриптами; собирается только если папка есть) и `GameProjectHub\GameProjectHub.exe` (без установки).

## Где хранятся данные и приватность

Установленная версия хранит всё в `%APPDATA%\GameProjectHub`: список игр, настройки, кэши. Steam API-ключ (нужен только для списка игр и часов) лежит в `settings.json` на вашем компьютере и никуда не отправляется. Приложение обращается только к Steam, сайтам игр и GitHub; телеметрии нет. Резервная копия не включает ключ.

## Устройство проекта

| Файл | Назначение |
|---|---|
| `app.py` | окно на pywebview и бэкенд: данные, Steam, трекер времени |
| `web/` | интерфейс (HTML, CSS, JavaScript) |
| `installer.py`, `installer_web/` | мастер установки и удаления |
| `build.py` | сборка приложения и установщика через PyInstaller |
| `assets/make_icon.py` | рисует иконку приложения |
